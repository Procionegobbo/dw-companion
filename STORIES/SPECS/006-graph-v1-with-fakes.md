# 006 - Graph v1 with fakes

**Status:** draft — to be expanded by spec-builder.
**Depends on:** 002 (move/section shapes), 005 (domain types and dice).
**Reference:** `HANDOFF_dw-companion.md`, sections 4.3, 4.4, 10 (milestone 5).

## Scope

Build the full LangGraph wiring against fake ports — no real LLM or vector store calls yet.

- `backend/ports/`: protocols for `LLMClient`, `Retriever`, `Tracer`, `RulebookRepository`.
- Fakes for every port in `backend/tests/fakes/`.
- `graph/` nodes:
  - **Router**: `{ intent: "rules_question" | "action_description" | "out_of_scope", confidence: float }`. If an action description also contains a rules question, prefer `action_description`.
  - **Rules branch**: `retrieve` → `answer_with_citations` → `citation_validator`. The
    validator is deterministic code (not an LLM): every cited ID must exist in the
    retrieved set; invalid citations are stripped and the event traced; if no valid citation
    remains, return "I couldn't find this in the rules" plus the closest sections as links.
  - **Move branch**: `classify_move` → (`clarify` | `explain`) → `[roll tool]` → `outcome`.
    Input is the user's description plus the full structured list of candidate moves (basic
    + special, not retrieved — included entirely, per section 4.4). Output schema:
    `{ move_id: string | "no_move", confidence: float, stat: "STR"|"DEX"|"CON"|"INT"|"WIS"|"CHA"|null, rationale: string, alternatives: [move_id] }`.
    `"no_move"` is a first-class outcome. Low confidence → one clarifying question instead
    of guessing. Explanation quotes the move's outcomes from structured data, never
    regenerated by the LLM. Dice via the domain `roll` tool from spec 005 — never invented
    by the LLM.
  - **Out of scope branch**: short reply saying what the assistant can do, no LLM call
    beyond the router.
- Every node and branch tested against the fakes — no network calls in this spec.

## Out of scope

- Real LLM/vector store/Langfuse adapters (spec 007).
- The retrieval index itself (spec 007) — the fake `Retriever` here returns canned results.
